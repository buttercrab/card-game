## Ownership

- `session.ts` owns canonical immutable action payloads, connection freshness, admission and its bounded in-memory operation journal. Receipt notification is sequenced and cannot replay superseded private views.
- `runtime.ts` owns the current draft/focus, exclusive surface lease, mount/candidate generations, measurement cache/deadline, visible frame bindings and execution ingress. Mounting never creates another session owner.
- `planner.ts` owns the single composition policy, delegated through the internal exact-child rows/columns kernel (`composition.ts`). The default remains numeric; `yogaComposition.ts` and `nativeComposition.ts` are comparison adapters with no session, input, measurement or presentation authority. Dock consumes measured identity/hand requirements; the frame consumes Dock. No legacy frame/dock/identity policy is called. Decision semantics come from neutral `table/decisionModel.ts`, `decisionCore.ts`, and `cardSelection.ts`; foundation never imports the retained `DecisionController` facade.
- `domSurface.ts` is the sole DOM geometry publisher and native measurement/event adapter. It renders explicit frame semantics; it does not discover layout roles from CSS classes or decide child positions.
- `fixtures.ts` supplies semantic data. `FoundationPreview.svelte` is a test workbench around the root, with controls to change fixture inputs, remount, revoke and increase text size. Its outer page layout supplies the host allocation; it does not position table children.

The public factory does not accept a custom planner. Static import checks reject legacy geometry/controller delegation in the new core, and compile-negative fixtures reject game-level geometry overrides. Internal planner injection supports adversarial unit tests only. These are trusted-code architecture controls, not a JavaScript security sandbox.

## Demonstrated behavior

Text requirements are measured at the exact font recipe and width in two batched stages. Missing measurements never become visible zero-size placeholders. A candidate must pass tree, containment, target-size and ordinary-sibling exclusion checks before publication. Deliberate card overlap is limited to a fan, with a minimum exposed strip and a declared horizontal scroll viewport.

The identity reserves its complete figure/halo, markers and wrapped name. A dock chooses side-by-side only when measured child requirements fit; otherwise it stacks. A taller document uses explicit vertical scrolling. Unsupported narrow widths produce a non-fit fallback rather than negative size clamping. Arrangement stays internal to exact-width preparation; applications cannot arrange a stale plan at a different width.

A runtime exclusively leases one surface. Detach releases listeners/probes/deadlines, clears the rendered frame and invalidates old callbacks. Reattachment preserves compatible runtime drafts and session operations, while issuing new frame identities. Revocation clears private DOM, metrics, drafts and focus. A whole-candidate 500ms measurement deadline ends stalled preparation; stale replies cannot revive it. Environment changes synchronously hide and inert incompatible geometry while retaining scoped leaves for the next atomic publication. Detach, revocation, failure and audience replacement still destroy retained DOM. Attach clears old measurement entries because fonts can change while detached and adapter generations can alias. An adapter-scoped loaded-font fingerprint (resource identity, matching/metric descriptors and order) lets compatible intrinsic/exact-width text metrics survive allocation changes. Duplicate [font completion notifications](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/loadingdone_event) preserve the generation; real resource changes invalidate it. The last runtime-reported environment is tracked separately from the adapter cache, so a pending input event cannot swallow a newer observation.

Native pointer/keyboard activation refers to a committed frame and exact action ID. Held gestures cannot cross resize, replacement or remount. Scoped blur cancellation cannot cancel a newer pointer press on a different control. Focus intent lives in the runtime and returns with compatible frames; the renderer does not reconstruct it from an already disabled DOM element.

Session admission records an operation before transmission. Caller-owned payload mutations cannot change a canonical admitted command. Unresolved operations survive renderer detachment and are not automatically resubmitted. Account replacement redacts private payloads and hides prior-actor operation views while retaining internal receipt tombstones. The journal refuses overflow; it does not evict unresolved evidence to admit another operation.

Controls render the shared design-system primitives (`.btn` and `.chip`). The DOM adapter reads their computed typography, padding and minimum height into the environment; measurement-cache keys include those metrics. The planner reserves a parent envelope for the chip pulse, expanded native target and button lip before placing siblings. CSS supplies appearance and animation; the engine still supplies every table control position and allocation.
