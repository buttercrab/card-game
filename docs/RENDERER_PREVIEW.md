# DOM coordinate engine preview

Open `/preview?engine=1` to review the canonical Svelte table with the shared DOM coordinate engine. The toolbar offers scene selection and creation of a real Mighty room. Scene selection uses preview fixtures; real-game creation enters an ordinary server room at `/r/<id>`.

Older `/preview?canvas=1` and `/preview?surfaceDemo=1` bookmarks open this same DOM preview. Canvas/DOM comparison controls and the application CanvasSurface mount are removed. Retired Canvas implementations and obsolete Canvas-specific tests are archived outside the checkout with their original file hashes. Historical frozen builds and verification artifacts remain retained; the runtime now uses canonical native artwork. A `renderer=canvas` query no longer changes application rendering.
