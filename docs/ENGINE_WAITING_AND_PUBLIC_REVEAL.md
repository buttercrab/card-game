# Waiting composition and timed public disclosure

This gate restores table semantics through the shared engine. It does not add a game-owned layout, native controller, or second transport.

## Waiting contract

`TableDocument.stage` declares `waiting` or `active`; omission retains the active recipe. Canonical ingress rejects waiting documents containing private hands, public face collections, outcomes, or deal/reveal/return transitions. Mighty and Poker derive waiting from public room lifecycle and ignore cached prehand State.

Waiting uses the public seat registry and exact declared setup-action references. Seat buttons reuse ordinary command/form admission. A player sees clockwise peers and a bottom local identity; a five-seat observer sees two upper, two lower, and one centered bottom seat. The engine paints a real compact neutral stock back, with its canonical stock count available to accessibility and subsequent counted-deal conservation. It paints no undealt hand tray, fake empty-hand caption, or zero-card opponent counters.

All information remains available. Compact viewports offer `테이블 정보` in one engine-owned readonly native dialog; wide viewports retain a measured scrolling information rail. Both reuse the same information/fact/scoreboard content. Local navigation cannot submit a server action, and stale frames or audience revocation cannot resurrect the dialog.

Peer artwork and names use shared presentation tokens; semantic text keeps the selected user scale. Local identity remains stronger. Portrait/tablet seated docks keep an adjacent avatar/name header above the full-width hand independently of the current decision or hand cardinality. Desktop side composition remains measured. Reserved reaction/cue content cannot move card endpoints merely by changing its text.

## Timed public disclosure

A misdeal fan uses only the server-authorized public cards projected into committed feedback. It is passive artwork: no hand/entity/owner/zone/action/inspection binding. One root-level engine layer is allowed, with bounded validated ownership and no command descendants. Its measured viewport band avoids the entire header and notice allocation, every enabled native target, and actual stock/own-count anchors. Peer decoration may be temporarily covered; command hit paths may not.

The fan adds no permanent arena height. Its passive tag is excluded only from the semantic card-transfer signature; canonical transfer entities, geometry, scope, current native hit paths, clipping, and count conservation are unchanged. Native publication hides the fan during an active transfer cohort. The cohort's idle notification can reveal only the current frame's fan. Hidden fan scrolling is removed from the Tab order and hidden programmatic focus is refused.

The native adapter acknowledges an exact current frame/event only after the first public card is within its real host and clipping ancestors. Runtime and coordinator independently reject stale, foreign, publication-time, or unmounted acknowledgements. The coordinator owns the sole four-second expiry, beginning at this acknowledgement rather than at the earlier audio/semantic cue. Duplicate publication, resize, and acknowledgement cannot restart it. Unpresented source-superseded events retire rather than appearing later as history. Revocation clears pending and active ownership.
