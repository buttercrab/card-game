# Requests for code

Methods and switches the researcher wants but the loop cannot run yet. The
researcher appends here (it never writes code); a person implements the
method runner (`ml/src/cardgame_ml/loop/methods/`), adds it to the
policy's `methods`, and marks the request done with the commit.

Each request: a heading with the date and a short name, then **why**
(the result or agenda item that asks for it), **what** (the smallest code
that answers it: a config switch, a method runner, a bot setting),
**expected value** and **size** (hours of work, compute to answer).
